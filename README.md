# Java OOP Concepts

A simple Java project demonstrating the fundamental concepts of Object-Oriented Programming (OOP).

## Concepts Covered

- Class and Object
- Constructor
- Encapsulation
- Inheritance
- Polymorphism
- Method Overloading
- Method Overriding
- Abstraction
- Interface

## Technologies Used

- Java
- Eclipse IDE

## Project Structure

```text
OOPConcepts
└── src
    └── oops
        └── OOPConcepts.java
```

## How to Run

1. Open the project in Eclipse.
2. Open `OOPConcepts.java`.
3. Right-click on the file.
4. Select **Run As → Java Application**.
5. View the result in the Console.
